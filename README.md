# Omoidebako

Personal tracker thing for Anime/Manga using [supabase](https://supabase.com) free tier, github pages, and public apis

# Setup

Create an account on [supabase.com](https://supabase.com) and setup a free tier project

In the SQL Editor paste the 'supabase-setup.sql' contents inside and run
which will setup your table and security permissions

Grab your Project URL and Publishable Key from the project overview page and paste it into config.js
and now you're free to use it locally or setup a pages site
